# SkyBlockESP

SkyBlockESP is a QOL mod, which shows you the exact locations of mobs trough walls.

⚠️ Disclaimer ⚠️ It is just a rendering mod, and it does not affect any gameplay, but it still can break the rules of some minecraft servers.

# Features
- **45t bestiary** and **13 other things** over **1** island is currently supported
- Command `/skyblockesp` or `/esp` to open the config
- Debug mode to analyze some mobs

# Islands
- Private Island (8 bestiary)
- Safari Island (37 bestiary and 13 other things)
