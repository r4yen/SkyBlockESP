# SkyBlockESP

SkyBlockESP is a QOL mod, which shows you the exact locations of mobs trough walls.
:warning:  Disclaimer :warning:  It is just a rendering side mod, and it does not affect any gameplay, but it still can break the rules of some minecraft servers.

# Features
- **35 entities** and **13 other things** over **1** islands is currently supported
- Command `/skyblockesp` or `/esp` to open the config
- Debug mode to analyse some mobs
